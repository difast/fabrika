# ТехФабрика — сайт онлайн-школы программирования для детей

Современный, быстрый и адаптивный сайт онлайн-школы программирования с продающими блоками,
тарифами, формами заявки и интеграцией с Telegram-ботом.

Построен на **Next.js 16 (App Router) + TypeScript + Tailwind CSS v4**.

---

## ✨ Возможности

- Продающий одностраничный лендинг: hero, преимущества, программы, тарифы, процесс, FAQ.
- **Тарифы** с автоматическим расчётом скидки 20% (старая цена зачёркнута, новая — рассчитана).
- **Формы заявки** в нескольких местах (hero, после тарифов, финальный CTA, footer, модальное окно).
- При выборе тарифа/направления значение **автоматически подставляется** в форму.
- **Отправка заявок в Telegram** через серверный API-эндпоинт (токен не хранится в коде).
- Валидация форм, honeypot и rate-limit против спама, понятные сообщения об ошибках.
- Отдельная страница **Политики обработки персональных данных** (`/privacy`).
- SEO: уникальные `title`/`description`, Open Graph, генерируемая OG-картинка, `robots.txt`,
  `sitemap.xml`, Schema.org (`EducationalOrganization`, `FAQPage`), семантическая разметка.
- Полная адаптивность, доступность, аккуратные анимации, тёмная техно-тема.

## 🗂 Где что редактировать

**Все тексты, цены, контакты и ссылки** находятся в одном файле:

```
src/config/site.ts
```

Здесь меняются:

- контакты (телефон, Telegram, WhatsApp, e-mail);
- бренд и SEO (название, домен, описание, ключевые слова);
- пункты меню;
- тексты hero, преимуществ, программ, процесса, FAQ;
- **тарифы и цены** (меняйте только `basePrice` и `discountPercent` — новая цена считается сама).

> Реквизиты оператора персональных данных (`ООО «ИНТЕГРО»`) также задаются в `site.ts`
> (`site.legalName`) и автоматически подставляются в текст политики.


## 🤖 Настройка Telegram-бота

Заявки с сайта отправляются в Telegram. Настройка занимает пару минут:

1. **Создайте бота.** Напишите в Telegram боту [@BotFather](https://t.me/BotFather),
   команда `/newbot`, следуйте инструкциям. В ответ получите **`TELEGRAM_BOT_TOKEN`**
   (вида `1234567890:AAE...`).

2. **Узнайте chat_id** (куда слать заявки):
   - **Личные сообщения:** напишите боту [@userinfobot](https://t.me/userinfobot) — он
     пришлёт ваш числовой ID. Это и есть `TELEGRAM_CHAT_ID`.
   - **Группа:** добавьте своего бота в группу, затем добавьте туда же @userinfobot —
     он покажет ID группы (начинается с `-100...`).

3. **Важно:** прежде чем бот сможет вам писать, **отправьте боту `/start`** (для личных
   сообщений) или напишите любое сообщение в группе с ботом.

4. **Пропишите переменные окружения** в `.env.local` (локально) или в панели хостинга:

   ```env
   TELEGRAM_BOT_TOKEN=ваш_токен
   TELEGRAM_CHAT_ID=ваш_chat_id
   ```

Заявка приходит в виде структурированного сообщения: имя, телефон, Telegram, возраст
ребёнка, направление, тариф, комментарий, дата/время и страница отправки.

## ☁️ Деплой (Timeweb)

Проект — стандартное Next.js-приложение (Node.js). Деплой настроен **автоматически по push
в ветку `main`** через Timeweb.

В настройках приложения на Timeweb:

- **Команда сборки:** `npm run build`
- **Команда запуска:** `npm run start`
- **Версия Node.js:** 20+ (рекомендуется 22)
- **Переменные окружения:** добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

> Не забудьте изменить домен в `src/config/site.ts` (`site.url`) на ваш реальный —
> он используется в canonical, Open Graph и sitemap.

```

├─ app/
│  ├─ api/lead/route.ts     # API-эндпоинт: приём заявок → Telegram

│  ├─ layout.tsx            # Метаданные, шрифты, Schema.org
│  ├─ page.tsx              # Главная страница (сборка секций)

│  ├─ robots.ts / sitemap.ts
│  └─ globals.css           # Тема и стили
├─ components/
│  ├─ sections/             # Секции: Header, Hero, Pricing, FAQ, Footer, …
│  ├─ lead/                 # Формы заявки и модальное окно
│  ├─ ui.tsx                # CTA-кнопка, анимации, заголовки
│  ├─ Icon.tsx / Logo.tsx
├─ config/site.ts           # ← ЕДИНЫЙ ФАЙЛ НАСТРОЕК (тексты, цены, контакты)
└─ lib/pricing.ts           # Расчёт и форматирование цен
```
